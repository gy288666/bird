# 怒鸟出击 · Furious Fowl

一款受经典物理弹射玩法启发的 HTML5 游戏：用弹弓把小鸟射向绿皮猪的堡垒，利用物理碰撞摧毁建筑、消灭所有小猪即可过关。**零依赖、零构建、零联网**——双击 `index.html` 即可游玩。

> 所有美术均为 Canvas 程序化绘制、所有音效均为 WebAudio 实时合成的原创内容。

## 快速开始

```bash
# 方式一：直接双击打开
open index.html

# 方式二：任意静态服务器（推荐，体验一致性更好）
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

支持桌面（鼠标）与移动端（触屏），自适应任意屏幕尺寸。

## 玩法

| 操作 | 说明 |
|------|------|
| 拖住弹弓上的小鸟向后拉，松手 | 发射（有弹道预览虚线） |
| 小鸟飞行中点击屏幕 | 释放该小鸟的专属技能 |
| 左上角 ⏸ / ↻ | 暂停 / 重玩本关 |

### 五种小鸟

| 小鸟 | 技能 |
|------|------|
| 🔴 红鸟 | 基础型，撞击结实 |
| 🟡 黄鸟 | 点击瞬间加速，专克木头 |
| 🔵 蓝鸟 | 点击一分为三，专克冰块 |
| ⚫ 黑鸟 | 点击（或高速撞击后）爆炸，专克石头 |
| ⚪ 白鸟 | 点击投下炸弹蛋并弹身飞离 |

### 材质与道具

- **木头**：中等硬度，黄鸟一击即穿
- **冰块**：脆，蓝鸟碎冰利器
- **石头**：坚硬，用黑鸟或 TNT 伺候
- **TNT**：被击中即爆炸，可连锁引爆

### 计分与星级

- 消灭小猪 +5000（猪王 +10000），破坏木/冰 +500、石头 +800、TNT +1000
- 过关后每只剩余小鸟 +10000
- 按总分评定 1~3 星，进度与最佳成绩自动保存在本地（localStorage）

## 关卡

共 **30 关**，按难度曲线分为六个篇章，逐步引入新小鸟与新机制：

1. **1-5 关**：木质结构教学（红鸟）
2. **6-10 关**：冰块与黄鸟加速
3. **11-15 关**：石头、蓝鸟分裂与高台地形
4. **16-20 关**：黑鸟爆破与 TNT 连锁
5. **21-25 关**：白鸟空投与混合材质
6. **26-30 关**：终局挑战，直至「猪王城堡」

## 技术架构

```
index.html          页面骨架 + UI 层（菜单/选关/HUD/结算）
css/style.css       UI 样式
vendor/matter.min.js  Matter.js 0.20（2D 刚体物理引擎，本地化）
js/audio.js         WebAudio 程序化音效合成
js/levels.js        30 关数据（结构生成器 DSL：塔/小屋/金字塔/平台）
js/game.js          核心：物理模拟、碰撞伤害、技能、粒子、Canvas 渲染
js/ui.js            界面流转 + localStorage 存档
js/main.js          入口
```

### 性能要点

- 固定 60Hz 物理步长 + `requestAnimationFrame` 渲染，帧率波动不影响手感
- Matter.js 开启 sleeping，静止物体不参与计算
- 整场物体数 < 100，渲染为单 Canvas 全程序化绘制，无图片解码/网络请求
- `devicePixelRatio` 感知（上限 2x），高分屏清晰且不过度耗电
